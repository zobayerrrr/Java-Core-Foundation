# Java Core & OOP Foundations ☕

A structured repository documenting my journey through core Java programming concepts, starting from fundamental control structures to advanced Object-Oriented Programming (OOP) and modern Java features.

## 📌 Topics Covered

- **Java Basics & Control Flow:** 
  - Variables, data types, and operators.
  - Branching statements (`if-else`, `switch`, ternary operator).
  - Iteration and loops (`for`, `while`, `do-while`, `break`, `continue`).
- **Object-Oriented Programming (OOP):** Encapsulation, Inheritance, Polymorphism, and Abstraction.
- **Java Collections Framework:** Dynamic arrays (`ArrayList`), LinkedLists, HashSets, TreeSets, HashMaps, and custom Comparators.
- **Exception Handling:** Try-catch blocks, custom exceptions, and resource management (`try-with-resources`).
- **File I/O & Streams:** Reading/writing files and handling data streams.
- **Java 8+ Features:** Lambda expressions, Streams API, and Optional handling.
